## `whoami`

I'm a **B.E. Artificial Intelligence & Machine Learning student at MITE** and **Co-Founder & Software Engineer at Vyanika Innovations**.

My work sits at the intersection of:

**Artificial Intelligence · Software Engineering · Distributed Systems · Embedded Systems · Research**

I enjoy taking problems that initially look like separate pieces — sensors, firmware, data, AI models, APIs, interfaces and infrastructure — and turning them into **one working system**.

Currently, my main focus is building **real-world AI systems and intelligent products**, while exploring how research ideas can be engineered into reliable, measurable systems.

### MULTI-AGENT AI

**MAWOS**

A controlled multi-agent research framework for evaluating:

* Agent orchestration
* Task decomposition
* LLM tool calling
* Role-scoped execution
* Event-driven workflows
* Reliability & fault isolation
* Reproducible evaluation

The system models a complete university environment and evaluates whether multi-agent orchestration actually improves workflow execution.

**Research question:**
How do we build agentic systems that are measurable, grounded and reliable — rather than simply adding more agents?

→ **[Explore MAWOS](https://github.com/samprith02/MAWOS)**

### SPORTS TECHNOLOGY

**Tech Kabaddi**

A real-time sensor officiating platform being developed through **Vyanika Innovations**.

The system combines:

* Pressure sensing
* NFC-based player identification
* Embedded firmware
* Binary communication protocols
* Real-time visualization
* Replay infrastructure
* Automated line-cross detection

The platform evolved from a prototype into a distributed real-time sensing architecture.

### FEDERATED LEARNING

**Federated Learning Simulation Framework**

Research implementation exploring distributed training with heterogeneous clients.

Current work includes:

* Federated Averaging (FedAvg)
* PyTorch
* CIFAR-10
* MNIST
* IID vs Non-IID training
* Dirichlet data partitioning
* 100 simulated clients

A reproduced MNIST IID baseline reached **99.02% accuracy**, followed by experiments studying the effect of client heterogeneity.
